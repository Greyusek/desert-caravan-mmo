# Desert Caravan MMO — Project Docs

Обновлено: 26 августа 2026

## Актуальный дизайн

- `Desert_Caravan_MMO_GDD_v0.5.docx` — главная точка входа: объединённые решения по путешествию, миру, информации, магии, экологии, System 256, presentation direction и будущим автономным Искинам.
- `WORLD_BIBLE.md` — канон мира: островки цивилизации, Старый мир, Катастрофа, возвращение магии, карты, библиотеки и города.
- `WORLD_BIBLE_BESTIARY.md` — канон существ, происхождение бестиария, постоянная экология, приручение и emergent-легенды.
- `SYSTEM_256.md` — каноническая архитектура семицветного круга, Белого/Чёрного, производных оттенков и трёх каналов существа; численный баланс остаётся открытым.
- `GDD_MAGIC.md` — мана, внешние источники заклинаний, свитки, ритуалы, накопители и городское исследование знания.
- `GDD_ECOLOGY.md` — механические следствия экологии, популяций, System 256, приручения и уровней детализации симуляции.
- `PRESENTATION_BIBLE.md` — главный экран, городские режимы, AFK-симуляция боя, ручное подключение и приоритеты визуала.
- `AI_ISKINS_CONCEPT.md` — принятый долгосрочный контракт NPC / AI Player, City AI, Species AI, Cognitive LOD и границы `Perception → Action → simulation`.
- `ROADMAP.md` — этапы разработки и критерии выхода.
- `MVP_SPEC.md` — спецификация MVP-0 и актуальный backlog.

## Архив GDD
