# Checkpoint 03 — SIM-006: food / water

Версия проекта: `0.0.3`

## Цель

Добавить первый настоящий риск экспедиции: конечные запасы еды и воды.

Движок должен уметь ответить не только «где находится караван?», но и:

- сколько еды и воды осталось через `T`;
- когда закончится первый критический ресурс;
- что закончится первым;
- хватит ли запасов до конца маршрута;
- как отличается расход в движении и на стоянке.

## Принятые упрощения MVP

1. Еда и вода пока измеряются абстрактными `units`.
2. Расход задаётся в `units / игровой час`.
3. Время расхода — время симуляции. Production-соотношение «1 игровой день = 3–4 реальных часа» пока не вшивается в simulation core.
4. Для текущего MVP `food = 0` или `water = 0` означает фатальное истощение экспедиции.
5. Позже мгновенную смерть можно заменить стадиями голода/обезвоживания без изменения базовой модели запасов.

## Реализовано

### `projectSupplies()`

Принимает:

- начальный запас food/water;
- нормы расхода `moving` и `idle`;
- текущий режим;
- прошедшее время.

Возвращает:

- сколько израсходовано;
- сколько осталось;
- произошло ли истощение;
- точный момент первого истощения;
- причину: `food`, `water`, `both`.

### `timeToFirstDepletion()`

Заранее вычисляет момент, когда закончится первый критический ресурс.

Это важно для будущего event-driven сервера: не нужно проверять запасы каждую секунду. Можно сразу запланировать событие на математически рассчитанный момент.

### `canSurviveDuration()`

Быстрая проверка, хватит ли запасов на заданную продолжительность режима.

## Тестовый сценарий demo

Маршрут Checkpoint 02:

- длина: `87 км`;
- скорость: `5 км/ч`;
- ETA: `17.4 ч`.

Запасы:

```text
food  = 12
water = 10
```

Расход в движении:

```text
food  = 0.5 / ч
water = 1.0 / ч
```

Следовательно вода заканчивается через `10 часов`.

К этому моменту караван при скорости `5 км/ч` проходит `50 км`, то есть не способен закончить 87-километровый маршрут.

На стоянке расход меньше:

```text
food  = 0.25 / ч
water = 0.4 / ч
```

## Автоматические тесты

Добавлено 10 тестов SIM-006. Всего в проекте должно быть:

```text
# tests 32
# pass 32
# fail 0
```

Проверяются:

- `T = 0`;
- линейный расход во времени;
- меньший расход на стоянке;
- вода заканчивается первой;
- еда заканчивается первой;
- одновременное истощение;
- нулевой расход;
- clamp остатка к нулю;
- точный момент истощения;
- отклонение отрицательных запасов/расхода/времени.

## Как проверить на Windows

В `D:\dev\newWorld` после распаковки UPDATE:

```powershell
npm.cmd install
npm.cmd test
npm.cmd run demo
```

Ожидаемый итог тестов:

```text
# tests 32
# pass 32
# fail 0
```

Ключевые строки demo:

```text
Total distance: 87.000 km
Total ETA: 17.400 h
At T=5h moving: food=9.500, water=5.000
First depletion: water at T=10.000 h, traveled=50.000 km
Can finish 17.4h route with these supplies: false
If idle for 10h instead: food=9.500, water=6.000
```
