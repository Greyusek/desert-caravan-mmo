# Ручная проверка Checkpoint 75 — PLAYER-CITY-001

Проверка выполняется после merge PR в `main`. Она не требует переключения на
служебную ветку и не использует Developer / Debug UI.

## 1. Обновить локальный проект

Откройте **Git Bash** и выполните команды по очереди:

```bash
cd /d/dev/newWorld
git switch main
git pull --ff-only origin main
npm ci
```

Если проект находится в другой папке, замените только `/d/dev/newWorld` на свой
путь. После `git switch main` терминал должен показывать ветку `(main)`.

## 2. Запустить Player UI

В том же окне Git Bash выполните:

```bash
npm run player-ui
```

Не закрывайте терминал. Дождитесь строки:

```text
Desert Caravan MMO Player UI: http://127.0.0.1:4174
```

Откройте в браузере <http://127.0.0.1:4174>. Если страница уже была открыта,
нажмите `Ctrl+F5`, чтобы полностью обновить её.

## 3. Тест 1 — городской экран

1. Дождитесь исчезновения надписи «Подготавливаем журнал каравана…».
2. Нажмите слева **Город**.
3. Убедитесь, что видны название **South Camp**, кошелёк, свободная вместимость,
   таблица из семи товаров и библиотека.
4. В строках **Руда** и **Лекарства** количество «В караване» должно быть больше
   нуля. Для товаров, которых нет в караване, кнопка продажи должна быть
   неактивна.

Ожидаемый результат: экран открывается без ошибок и показывает только игровые
данные, без seed, координат и DEV-кнопок.

## 4. Тест 2 — покупка товара

1. Запомните кошелёк, свободную вместимость, городской остаток и количество в
   караване для строки **Еда**.
2. Нажмите **Купить** в строке «Еда» один раз.
3. Проверьте изменения:
   - кошелёк уменьшился ровно на сумму на кнопке;
   - «В городе» уменьшилось на 1;
   - «В караване» стало больше на 1;
   - свободная вместимость уменьшилась;
   - появилась строка об успешной покупке.

## 5. Тест 3 — продажа товара

1. В строке **Руда** нажмите **Продать** один раз.
2. Проверьте изменения:
   - кошелёк увеличился ровно на сумму на кнопке;
   - городской остаток руды увеличился на 1;
   - количество руды в караване уменьшилось на 1;
   - свободная вместимость увеличилась.

## 6. Тест 4 — передача физических сведений

1. В блоке **Библиотека** найдите карточку «След каравана».
2. Убедитесь, что указаны источник, доверие, сохранность и оценка в кредитах.
3. Запомните кошелёк и нажмите **Передать в архив**.
4. Проверьте, что кошелёк вырос на указанную оценку, счётчик архива стал
   `1 запись`, а карточка исчезла.
5. Повторно передать тот же свиток невозможно.

## 7. Тест 5 — сохранение Global Map

1. Нажмите слева **Карта**.
2. Выберите **North Camp**, нажмите **Проложить маршрут**, затем
   **Отправить караван**.
3. Убедитесь, что карта показывает караван в пути, а разделы **Город** и
   **Караван** становятся недоступными.

Ожидаемый результат: городские операции не ломают ранее принятую карту и
маршрут.

## 8. Завершение

Вернитесь в Git Bash и остановите сервер сочетанием `Ctrl+C`.

Если все пять тестов прошли, достаточно написать: **«Checkpoint 75 принят»**.
При ошибке приложите скриншот страницы, текст из консоли браузера и вывод из
Git Bash.
