# Checkpoint 05 — WORLD-002: hidden static world objects

Version: `0.0.5`

## Goal

Add reproducible server-side points of interest without exposing them through a player-facing DTO, map, or UI, and without changing the cities generated by `WORLD-001`.

## Implemented

- four ordered object kinds: `oasis`, `mine`, `ruins`, and `cave`;
- stable per-kind IDs and spherical positions in the safe latitude/longitude ranges;
- one object of every kind by default;
- partial `staticObjectCounts` configuration, including zero for focused tests;
- an independent namespaced PRNG stream for every object kind;
- unchanged city identities and coordinates for existing seeds;
- demo output for the hidden server-side object list after the cities.

The objects remain authoritative world data. This checkpoint deliberately adds no discovery rules, detection radius, fog of war, player DTO, map, server, or persistence.

## Automated verification

WORLD-002 tests cover default contents and order, stable unique IDs, coordinate ranges, deterministic replay, seed variation, count validation, and independence from city and other-kind counts. Golden tests pin both the `checkpoint-04` cities and the new static object list to literal expected values.
