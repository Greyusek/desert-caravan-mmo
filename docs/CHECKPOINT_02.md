# Checkpoint 02 — SIM-004 + SIM-005

Версия проекта: `0.0.2`

## Цель

Проверить две фундаментальные способности simulation core:

1. строить составной маршрут из нескольких команд `азимут + расстояние`;
2. вычислять положение каравана в любой момент времени `T` без постоянного обновления координат каждую секунду.

## Что реализовано

### SIM-004 — составной маршрут и ETA

`createRoutePlan()`:

- принимает стартовую серверную координату;
- принимает список сегментов `bearingDeg + distanceMeters`;
- принимает скорость каравана;
- строит конечную точку каждого сегмента;
- связывает сегменты друг с другом;
- считает общую длину;
- считает ETA каждого сегмента и всего маршрута.

Тестовый маршрут:

1. `315° / 20 км`
2. `270° / 12 км`
3. `225° / 20 км`
4. `90° / 35 км`

При скорости `5 км/ч`:

- общая длина = `87 км`;
- общий ETA = `17.4 часа`.

### SIM-005 — положение во времени

`positionAtTime(route, T)` вычисляет:

- текущую координату;
- текущий сегмент;
- прогресс внутри сегмента;
- пройденное расстояние;
- оставшееся расстояние;
- статус `moving` / `arrived`.

Серверу не требуется каждую секунду физически передвигать караван в БД. Координата восстанавливается математически из маршрута и времени.

## Автоматические тесты

В проекте теперь 22 теста:

- 12 тестов Checkpoint 01;
- 10 новых тестов SIM-004/SIM-005.

Проверяются в том числе:

- цепочка из четырёх сегментов;
- сумма расстояний;
- накопление ETA;
- сохранение длины каждого сегмента на сфере;
- `T = 0`;
- середина первого сегмента;
- точная граница двух сегментов;
- время после прибытия;
- некорректное отрицательное время.

## Как проверить на Windows

Открой PowerShell в `D:\dev\newWorld` и выполни по одной команде:

```powershell
npm.cmd install
npm.cmd test
npm.cmd run demo
```

Ожидаемый итог тестов:

```text
# tests 22
# pass 22
# fail 0
```

Ключевые строки demo:

```text
Total distance: 87.000 km
Total ETA: 17.400 h
At T=5h: segment=2, traveled=25.000 km, remaining=62.000 km
Segment distance check: 87.000000 km
```

Checkpoint закрывается только после того, как эти тесты пройдут на рабочем компьютере пользователя.

После этого следующий маленький этап: `SIM-006` — расход воды и еды во времени.
