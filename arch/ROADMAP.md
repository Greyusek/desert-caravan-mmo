# Desert Caravan MMO — ROADMAP

**Версия:** 0.2  
**Дата:** 14 августа 2026  
**Статус:** development / MVP-0  
**Текущий checkpoint:** `SIM-001..SIM-003`

## Как читать roadmap

Roadmap построен по принципу **«маленький проверяемый этап → тест → только потом следующий слой»**. Результат работающего прототипа имеет приоритет над теоретическим GDD.

## Этап 1 — MVP-0 «Экспедиция в неизвестность»

**Цель:** доказать, что сама дорога интересна без полноценной боёвки.

### 1.1 Геометрия мира
- [x] Сферическая модель как первая реализация.
- [x] Скрытые абсолютные координаты как дизайн-правило.
- [x] Вычисление точки по `start + bearing + distance`.
- [ ] Маршрут из нескольких сегментов.
- [ ] Расстояния и ETA маршрута.
- [ ] Положение каравана в момент T.

### 1.2 Караван
- [ ] Скорость движения.
- [ ] Вода и еда.
- [ ] Разный расход в движении и на стоянке.
- [ ] Гибель от истощения.
- [ ] Пауза / продолжение маршрута.

### 1.3 Мир и открытия
- [ ] ~10 городов.
- [ ] Скрытые статичные объекты: оазис, рудник, руины, пещера.
- [ ] North-up карта без абсолютных координат.
- [ ] Туман войны.
- [ ] Базовый обзор 300 м / скрытый объект 150 м.
- [ ] Обнаружение объекта только при реальном сближении.
- [ ] Личная карта открытий.
- [ ] Слух вида «объект примерно в секторе/радиусе».

### 1.4 Движущиеся опасности
- [ ] Блуждающий монстр с циклическим маршрутом.
- [ ] Затаившийся монстр.
- [ ] Player Power 100; monsters Power 90 / 110 как заглушка до боя.
- [ ] Проверить соотношение interaction radius 500 м и base vision 300 м.
- [ ] Разные времена прохождения точки = отсутствие встречи.

### 1.5 Доктрина и офлайн
- [ ] Безопасного offline mode нет.
- [ ] «остановиться у объекта» / «отметить и идти дальше».
- [ ] «обойти обнаруженную опасность».
- [ ] аварийное действие по порогу провизии.
- [ ] автопокупка провизии в городе при наличии денег и запасов.
- [ ] переход в другой известный город при дефиците.
- [ ] журнал: что увидел отряд и почему принял решение.

### 1.6 Городские запасы — минимальная модель
- [ ] конечные food/water stocks.
- [ ] потребление NPC.
- [ ] дефицит способен уменьшать население.
- [ ] без production chains и сложного ценообразования.

### 1.7 Инструменты теста
- [ ] x1 / x10 / x100 / x1000 скорость симуляции.
- [ ] debug-overlay с настоящими координатами и радиусами (только dev mode).
- [ ] воспроизводимый seed.

**Exit criteria MVP-0:** игрок получает слух, самостоятельно строит поисковый маршрут, может найти или пропустить объект, встречает/избегает движущуюся угрозу, расходует запасы и возвращается либо погибает. После одного завершённого похода хочется спланировать следующий.
