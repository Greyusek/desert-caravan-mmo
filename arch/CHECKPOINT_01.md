# Checkpoint 01 — локальная проверка SIM-001..SIM-003

Цель: подтвердить на рабочем компьютере, что базовая сферическая геометрия проекта работает до перехода к составным маршрутам.

## Что уже реализовано

- `SIM-001` — координаты мира, метры/километры, нормализация азимута и долготы;
- `SIM-002` — вычисление точки по `start + bearing + distance`;
- `SIM-003` — расстояние по большой окружности;
- проверка перехода через границу `+180° / -180°`;
- радиус планеты передаётся параметром и пока не считается production-решением.

## Проверка на Windows PowerShell

1. Распаковать архив проекта в удобную папку.
2. Открыть PowerShell в папке `desert-caravan-mmo`.
3. Выполнить:

```powershell
node --version
npm --version
npm install
npm test
npm run demo
```

## Ожидаемый результат

`npm test` должен закончиться строками примерно такого вида:

```text
# tests 12
# pass 12
# fail 0
```

`npm run demo` должен закончиться:

```text
Measured great-circle distance: 100.000000 km
```

Координата `Destination` может содержать много знаков после запятой — это нормально.

## Правило перехода дальше

Пока этот checkpoint не подтверждён на рабочем компьютере, `SIM-004` и `SIM-005` не начинаем.
